To add a new reference:

1. Add it to the bib-file

2. Run the following command in the references directory:

pandoc -f markdown -t markdown_mmd+yaml_metadata_block-raw_html+strikeout --bibliography=fintel-works.bib --csl=unified-kvf-works.csl --wrap=none --citeproc work-template.md -o work.md -s

   (The +strikeout extension is what makes the ~~since~~ title in
   2019-fintel-iatridou-since come out right. The bib field must use ulem's
   \sout{...}, not soul's \st{...}: pandoc's biblatex reader knows \sout and
   turns it into a real strikeout, but silently drops \st. No hand-editing of
   work.md is needed any more.)

3. Copy the resulting work.md file to the content directory, overwriting the previous versions

4. Push the commit to github; netlify will detect and deploy the new version
